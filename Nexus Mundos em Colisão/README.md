# NEXUS: Mundos em Colisão

Site promocional fictício criado para o Game Web Challenge TIIN.

## Conceito
Uma ruptura funde os universos de GTA V, Minecraft, Ghost of Tsushima e Red Dead Redemption 2. O protagonista precisa atravessar os quatro mundos e recuperar os Núcleos de Origem para restaurar suas fronteiras.

## Como executar
1. Extraia a pasta do projeto.
2. Abra a pasta no VS Code.
3. Abra `index.html` com Live Server (recomendado) ou diretamente no navegador.
4. Mantenha as pastas `css`, `js` e `img` junto aos arquivos HTML.

## Páginas
- `index.html`: campanha e apresentação dos quatro mundos.
- `sobre.html`: história, universos e mecânicas.
- `galeria.html`: imagens com ampliação ao clicar.
- `loja.html`: edições e simulação de compra (sem pagamento real).

## Tecnologias
HTML5, CSS3 e JavaScript puro.

## Equipe e GitHub
Preencha abaixo com os integrantes, usuários GitHub e responsabilidades. Cada integrante deve fazer pelo menos 2 commits próprios e 1 push no repositório compartilhado, conforme o desafio.

| Integrante | Usuário GitHub | Responsabilidade |
|---|---|---|
| Integrante 1 | @usuario | Página inicial |
| Integrante 2 | @usuario | Loja e simulação de compra |
| Integrante 3 | @usuario | Galeria e imagens |
| Integrante 4 | @usuario | Sobre, revisão e integração |

## Observação
NEXUS é um projeto conceitual/fan crossover para fins escolares. GTA V, Minecraft, Ghost of Tsushima e Red Dead Redemption 2 pertencem aos seus respectivos titulares. Não há afiliação oficial.
